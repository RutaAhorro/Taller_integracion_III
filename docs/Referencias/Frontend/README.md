# 🎨 Frontend & Construcción

Esta sección engloba las buenas prácticas para la codificación y protección del lado del cliente. Enfocada en el desarrollo de la aplicación web (React/Vite), su interactividad, diseño y pruebas.

## Capítulos Incluidos

* **[Capítulo 4: Software Construction](Swebok-Cap-04-Software-Construction.md)**
  Abarca la "construcción" o codificación. Incluye buenas prácticas de programación, estructuración de componentes, manejo de estado y diseño interactivo.

* **[Capítulo 5: Software Testing](Swebok-Cap-05-Software-Testing.md)**
  Metodologías de pruebas. Útil para asegurar la calidad de la interfaz (pruebas unitarias de componentes, UX/UI y responsividad).

* **[Capítulo 13: Software Security](Swebok-Cap-13-Software-Security.md)**
  Enfocado en la protección y seguridad del sistema. En el contexto de frontend, es clave para la mitigación de vulnerabilidades (como XSS o CSRF) y la validación de inputs del lado del cliente.
