Esta carpeta incluye los recursos del SWEBOK centrados en operaciones, servidores, despliegues e integración continua. Es material clave para la arquitectura de infraestructura (clúster UCT, Docker, PostgreSQL, etc.).

## Capítulos Incluidos

* **[Capítulo 6: Software Engineering Operations](Swebok-Cap-06-Software-Engineering-Operations.md)**
  Trata sobre mantener el software vivo: monitorización, manejo de servidores, optimización de recursos y planes de contingencia operativa.

* **[Capítulo 8: Software Configuration Management](Swebok-Cap-08-Software-Configuration-Management.md)**
  Alineado con prácticas como GitFlow y CI/CD. Abarca el manejo de entornos (desarrollo vs producción), versionado de código e infraestructura, y la gestión de releases.
