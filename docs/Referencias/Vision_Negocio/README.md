# 🏢 Visión de Negocio

Esta carpeta contiene los capítulos del SWEBOK orientados a la gestión, monetización, roles y profesionalismo en la ingeniería de software. Es lectura recomendada para Scrum Masters, Product Owners y encargados de definir el rumbo del proyecto.

## Capítulos Incluidos

* **[Capítulo 9: Software Engineering Management](Swebok-Cap-09-Software-Engineering-Management.md)**
  Aborda la gestión pura del proyecto. Ayuda a planificar recursos, estimar tiempos y medir el éxito y alcance de los entregables del equipo (Scrum/Agile).

* **[Capítulo 14: Software Engineering Professional Practice](Swebok-Cap-14-Software-Engineering-Pofessional-Practice.md)**
  Define las reglas del juego a nivel profesional: contratos, ética, propiedad intelectual (copyrights, secretos comerciales) e interacción con stakeholders (clientes/inversores).

* **[Capítulo 15: Software Engineering Economics](Swebok-Cap-15-Sofrware-Engineering-Economics.md)**
  Se centra en el pilar financiero del negocio. Habla sobre la toma de decisiones de inversión, modelos de negocio, cálculo de valor y priorización.
